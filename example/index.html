bun-optimize-plugin

Every asset below is referenced by its original extension. The plugin rewrites each reference to the optimized file at build time.

Still images → WebP

Animated images → animated WebP

Video → WebM, VP9 and Opus

Audio → WebM, Opus

Everything else → copied unchanged

The HTML bundler does not follow <a href>, so these two files reach the bundle through an import in frontend.ts.
